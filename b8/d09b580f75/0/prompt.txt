min_version
A plain string is a hard minimum. Older mise releases stop with an error and print upgrade instructions:

1
min_version = "2026.1.0"


Add a soft minimum to warn without failing:

1
min_version = { hard = "2025.6.0", soft = "2026.1.0" }


Set hard to the oldest release that understands this file and soft to the release you want teammates on. { soft = "2026.1.0" } on its own is also valid.
